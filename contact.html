Contact ​

PieTeams works in public. The most reliable way to reach us is through GitHub, where every request is tracked and visible to the community.

Project support ​

Use the issue tracker of the relevant repository:

ProjectIssue tracker
PieKBSgithub.com/pieteams/piekbs/issues
PieMDMgithub.com/pieteams/piemdm/issues
PiePLMgithub.com/pieteams/pieplm/issues
This websitegithub.com/pieteams/pieteams.github.io/issues

Please include:

  • what you were trying to do
  • the version or commit you used
  • the exact command or page involved
  • what happened, and what you expected

Security reports ​

Do not open a public issue for a vulnerability. Use the Security tab of the affected repository and choose Report a vulnerability to send a private advisory. We will acknowledge the report and coordinate a fix and disclosure.

Documentation corrections ​

A broken link, an outdated command or an unclear paragraph is a bug. Open an issue or submit a pull request directly. If you are unsure which project owns a page, use the website repository.

Advertising and privacy ​

For questions about advertising, cookies or data handling, read the privacy policy. If the policy does not answer your question, open an issue in the website repository and describe the concern.

Business and partnership enquiries ​

PieTeams is an open-source project, not a consulting firm. We do not provide paid implementation services or endorsements. If your question can be answered in public, use the issue tracker so that others benefit from the answer.

Response expectations ​

This is a maintainer-led project. Issues are reviewed as time allows. A clear, reproducible report is much easier to act on than a general question, and it will usually receive a faster response.
